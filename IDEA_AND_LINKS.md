## 💡 The Pexy AI Idea

### **What is Pexy AI?**

**Pexy AI** is a comprehensive AI-powered platform that gives users multiple ways to interact with AI:

#### **6 Core Features:**

1. **💬 Chat with AI**
   - Text-based Q&A
   - 5 different AI personas
   - Conversation history
   - **NEW: Voice input** (speak to AI)
   - **NEW: Image upload** (AI analyzes images)

2. **🎨 Image Generation**
   - DALL-E 3 integration
   - Multiple styles & sizes
   - Prompt enhancement
   - Image gallery

3. **🎬 Video Generation**
   - Text-to-video
   - Keyframe preview
   - Customizable FPS & resolution
   - Duration control

4. **🔧 Code Assistant**
   - Debug code
   - Generate code
   - Explain code
   - 15+ language support

5. **🎤 Voice AI**
   - Text-to-speech
   - 6 different voices
   - Speed adjustment
   - Audio playback

6. **🖼️ Image Analysis**
   - Describe images
   - Extract text (OCR)
   - Custom questions
   - Vision AI

## 💻 Quick Commands Reference

```bash
# Clone project
git clone https://github.com/renkarl1803/goal.git
cd goal

# Install dependencies
npm install

# Run locally
cd apps/api && npm run dev      # Terminal 1
cd apps/web && npm run dev      # Terminal 2

# Deploy
cd apps/api && railway up       # Backend
# Push to GitHub and Vercel deploys frontend automatically

# View logs
railway logs                    # Backend logs
# Vercel logs in dashboard
```
